Shared Renovate presets for [kickr](https://github.com/kickr-dev/kickr) projects.

They serve three purposes:
- **Keep `kickr` templates up to date**: Versions in the CLI templates (`.tmpl` files) are updated here, at the source.
- **Delegate industrialization updates to `kickr`**:
  Projects generated by `kickr` get their CI, pre-commit and other layout files from the templates.
  Renovate updates on those files are disabled, so they only change through a `kickr` layout update.
- **Provide a base for dependency updates**: Updates are grouped to avoid a flood of pull requests, with opinionated disables and automerge rules for production dependencies.

All presets live under [configs](./configs/renovate/).

## Usage

Extend `default.json` plus the presets matching the ecosystems of the repository in its `renovate.json`.

```json
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": [
    "github>kickr-dev/renovate//configs/renovate/default.json",
    "github>kickr-dev/renovate//configs/renovate/gitlab-ci.json",
    "github>kickr-dev/renovate//configs/renovate/gomod.json"
  ]
}
```

Options set in the repository itself take precedence over the extended presets.

## Presets

| Preset                                                   | Description                                                                          |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [default](./configs/renovate/default.json)               | Base policy, grouping, vulnerability alerts, lockfile maintenance and regex managers |
| [docker](./configs/renovate/docker.json)                 | Groups Docker updates and tracks `ENV` versions in Dockerfiles                       |
| [github-actions](./configs/renovate/github-actions.json) | Tracks `uses` versions and semantic-release plugins in GitHub Actions files          |
| [gitlab-ci](./configs/renovate/gitlab-ci.json)           | Tracks images, `ref`, `component` and `remote` versions in GitLab CI/CD files        |
| [gomod](./configs/renovate/gomod.json)                   | Go modules grouping, tidy, `go generate` and automerge, without `go` directive bumps |
| [hugo](./configs/renovate/hugo.json)                     | Hugo modules and themes updates, with `hugo mod tidy`                                |
| [kickr](./configs/renovate/kickr.json)                   | Disables regex managers on files templated by `kickr`                                |
| [pre-commit](./configs/renovate/pre-commit.json)         | Groups pre-commit updates and tracks `rev` versions in template files                |
| [terraform](./configs/renovate/terraform.json)           | Terraform and OpenTofu grouping and docker image references in variables             |

### hugo

Runs `hugo mod tidy` instead of `go mod tidy`, which would remove themes as unused indirect dependencies.
Use it alongside `gomod`, with the `go.mod` paths of the Hugo sites separated by `|`.

```json
{
  "extends": [
    "github>kickr-dev/renovate//configs/renovate/hugo.json(go.mod|docs/go.mod)"
  ]
}
```
